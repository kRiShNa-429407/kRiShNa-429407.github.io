# Krishna Kaushik — Portfolio

A responsive, accessible static portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a repository named `kRiShNa-429407.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

The site uses plain HTML, CSS, and JavaScript, so no build step is required.

The published address will be `https://krishna-429407.github.io/`.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Customize

- Edit content and links in `index.html`.
- Adjust colors and layout variables at the top of `styles.css`.
- Replace `assets/Krishna_Kaushik_Resume_2026.pdf` when the résumé changes.
